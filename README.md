# ILDA Laser Sim

ILDAレーザー（ガルバノスキャナが点を1つずつ高速でなぞる方式）を模した、1920×1080のレーザー素材ジェネレーターです。
OBSで取り込み、UnityのボリュメトリックライトにVideo Textureとして入れる用途を想定しています。

## 起動
- Mac: `start.command` をダブルクリック
- Windows: `start.bat` をダブルクリック（Python 3 が必要）
- 手動: `python3 serve.py [ポート]`（デフォルト 8765）

同じLAN内の別PCからは、起動時に表示される `http://<IP>:8765/` でアクセスできます。

## OBS
1. ブラウザで設定を調整し「OBS用URLをコピー」を押す
2. OBSでブラウザソースを追加し、URLに貼り付け、幅1920・高さ1080に設定

`?obs=1` 付きのURLではUIが表示されません。キーボードの H でUIの表示と非表示を切り替えます。

## マウス操作
- ドラッグ: 位置を移動
- ホイール: サイズ
- Shift+ドラッグ / Shift+ホイール: 角度
- ダブルクリック: 中央に戻す

## 動画書き出し
パネル下部の「録画開始」で、1920×1080の動画を保存します（ChromeならMP4、それ以外はWebM）。
長さは5〜60秒、または手動停止から選べます。録画中はタブを切り替えないでください。

## 別の画面からの操作
サーバー経由で開いている場合は、操作画面（`?obs=1` なし）で変えた設定がOBS画面（`?obs=1`）にリアルタイムで反映されます。
設定とアニメーションの位置はブラウザにも保存されるので、リロードしても元に戻りません。
操作画面は同じLAN内の別のPCやタブレットで開いても構いません。

複数の出力を別々に操作したいときは、`?ch=名前` でチャンネルを分けます。
例: 操作画面 `/?ch=left`、OBS側 `/?obs=1&ch=left`

## 開発（HMR）
サーバー経由で開いているページは、`index.html` などを保存すると自動でリロードされます（設定はサーバー側に残ります）。
`serve.py` を保存するとサーバーが自動で再起動します。共有設定は `.state.json` に保存され、再起動後も引き継がれます。
